# دستیار آشپزخانه خانواده ایرانی (Iranian Family AI Cooking Assistant)

نمونه اولیه کامل و تعاملی رابط کاربری (Interactive UI Prototype) برای وب‌اپلیکیشن «دستیار تصمیم‌گیری و آشپزی مشارکتی خانواده ایرانی» بر پایه PRD نسخه ۱.۰.

---

## 🌟 ویژگی‌ها و بخش‌های پیاده‌سازی‌شده

این نمونه اولیه شامل تمام صفحات و جریان‌های کلیدی در قالب یک معماری مدرن SPA با فونت وزیرمتن و پشتیبانی کامل RTL است:

1. **جریان ورود و آشنایی (Onboarding):**
   - صفحه خوش‌آمدگویی و معرفی ارزش‌ها
   - تنظیمات اعضای خانواده و نقش‌ها
   - پروفایل سلامت و رژیم‌های غذایی (حساسیت‌ها، بیماری‌ها، ترجیحات)
   - موجودی اولیه و تجهیزات آشپزخانه
2. **داشبورد اصلی (Home Dashboard):**
   - پیشنهاد هوشمند وعده روز با تطابق درصدی و دلایل هوش مصنوعی
   - هشدار مواد رو به انقضا در انبار
   - برنامه غذایی هفته در یک نگاه
   - وضعیت تقسیم کارهای آشپزخانه اعضای خانواده
   - دسترسی سریع به گردونه انتخاب غذا، اسکن رسید و لیست خرید
3. **موتور پیشنهاد غذا (Food Recommendation):**
   - فیلترهای چندگانه (زمان، بودجه، تجهیزات، رژیم)
   - نمودار راداری شاخص‌های تغذیه‌ای و تناسب
4. **گردونه هوشمند شانس (Smart Wheel):**
   - انیمیشن چرخش و انتخاب تصادفی هوشمند غذا
5. **جزییات دستور پخت (Recipe Details):**
   - مشخصات، جدول ارزش غذایی، مواد اولیه با قابلیت افزودن به لیست خرید
   - مراحل قدم‌به‌قدم پخت
6. **حالت آشپزی گام‌به‌گام (Step-by-Step Cooking Mode):**
   - تایمر هوشمند معکوس با قابلیت کنترل
   - راهنمای صوتی و دکمه‌های ناوبری بزرگ مناسب محیط آشپزخانه
7. **برنامه‌ریز هفتگی غذا (Weekly Meal Planner):**
   - نمای روزانه و هفتگی برای صبحانه، ناهار، شام و میان‌وعده
8. **مدیریت انبار و یخچال (Pantry Inventory):**
   - دسته‌بندی مواد، تاریخ انقضا، ثبت مواد مصرفی و رو به اتمام
9. **اسکن و ثبت هوشمند رسید (Receipt / Bill Scanner):**
   - شبیه‌ساز استخراج اقلام خرید و افزودن خودکار به انبار
10. **لیست خرید هوشمند (Smart Shopping List):**
    - تفکیک اقلام خریداری‌شده و باقیمانده، تخمین هزینه کل
11. **مقایسه قیمت فروشگاه‌ها (Store Price Comparison):**
    - مقایسه قیمت اقلام بین فروشگاه‌های آنلاین (اسنپ‌مارکت، دیجی‌کالا جت، افق کوروش و...) با ارجاع لینک خارجی
12. **وظایف و همکاری خانوادگی (Family & Shared Tasks):**
    - لیست وظایف آشپزخانه، پاداش‌ها و تابلوی امتیازات
13. **گزارش‌ها و تحلیل‌ها (Reports & Analytics):**
    - گزارش بودجه و هزینه‌های ماهانه
    - گزارش سلامت و تنوع غذایی خانواده
14. **دستیار هوشمند تعاملی (AI Assistant Bottom Sheet):**
    - گفتگوی متنی/صوتی همراه با کارت‌های تاییدیه انسانی (Human-in-the-Loop Confirmation) برای تغییرات حساس
15. **تنظیمات و شخصی‌سازی (Settings):**
    - سوئیچ تم تاریک و روشن (Dark / Light Mode)
    - تنظیمات پروفایل و اعلان‌ها

## 🚀 نحوه اجرا

این پروژه با استاندارد خالص Vanilla HTML5 / Modern CSS / JavaScript ساخته شده و نیاز به هیچ بیلد یا پیش‌نیاز سنگینی ندارد:

```bash
# کلون کردن پروژه
git clone https://github.com/navidtrk7/ai-cooking-assistant-.git
cd ai-cooking-assistant-

# اجرا با سرور پایتون یا هر وب‌سرور دلخواه
python3 -m http.server 3000
```
سپس در مرورگر آدرس `http://localhost:3000` را باز کنید.
