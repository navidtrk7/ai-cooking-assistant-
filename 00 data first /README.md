# دستیار هوشمند آشپزخانه خانواده ایرانی — MVP

این بسته، مبنای ساخت MVP «دستیار تصمیم‌گیری و آشپزی مشارکتی خانواده ایرانی» است.

## محتویات

- `docs/01-product-scope.md`: دامنه محصول، مسئله، اهداف و خارج از دامنه.
- `docs/02-personas-and-journeys.md`: پرسوناها و سفرهای کاربر.
- `docs/03-feature-prioritization.md`: اولویت‌بندی MoSCoW و فازها.
- `docs/04-prd-mvp.md`: نیازمندی‌های محصول و معیارهای پذیرش.
- `docs/05-technical-architecture.md`: طراحی Front-end، Back-end، داده و امنیت.
- `prompts/antigravity-master.md`: پرامپت مرجع برای توسعه مرحله‌ای در Anti-Gravity.
- `index.html`: نمونه مستقل و تعاملی رابط Type C.

## اجرای نمونه رابط

فایل `index.html` را مستقیم در مرورگر باز کنید. برای تجربه نزدیک‌تر به PWA می‌توان آن را با یک وب‌سرور محلی ساده اجرا کرد:

```bash
cd kitchen-assistant-mvp
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## تصمیم‌های تثبیت‌شده

- محصول فارسی، RTL، موبایل‌محور و خانواده‌محور است.
- AI و Voice لایه اصلی تجربه هستند، اما هیچ تغییر حساس را بدون تأیید کاربر اعمال نمی‌کنند.
- سلامت شامل قواعد ثبت‌شده توسط کاربر است؛ «ثبت‌شده توسط کاربر» با «تأیید پزشکی» متفاوت است.
- خرید MVP با Link-out و مقایسه محدود انجام می‌شود؛ پرداخت داخل محصول نیست.
- مدل توسعه: React PWA + FastAPI + PostgreSQL + Ollama Adapter، با معماری Modular Monolith.
